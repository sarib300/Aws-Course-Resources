# 🚀 How to Contribute

Students can contribute by following these steps:

### Step 1 — Fork Repository

Click **Fork** on the top-right of the repository.

### Step 2 — Add Your Resource

Upload your files inside:

```
15_Students_Contributions
```

Examples:

* notes.pdf
* aws_architecture_diagram.png
* study_guide.md

### Step 3 — Create Pull Request

Submit a **Pull Request** so the maintainer can review your contribution.
